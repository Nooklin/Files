# Changelog

All notable changes to Nooklin Files, newest first. Each GitHub release has its own notes with the APK hashes.

## Version 1.0.0

First release. It includes everything built during the 0.0.x versions:

- File manager: browse, search, sort, four folder views, second pane, copy, move, rename, delete with own trash, zip with or without password, properties, batch rename
- Nextcloud (WebDAV), FTP and SMB servers, with background transfers
- Text editor, image, video, music, PDF, DOCX and EPUB viewers, Media3 playback with mini player and picture in picture
- Home with Favorites and Locations, Recents, Storage, Media and App Manager
- Settings laid out like the other Nooklin apps: Appearance (theme, font, contrast color, colorful tiles, show hidden files), Privacy (App Lock, Disable Screenshots, Share), Permissions, Help and About
- English and Dutch
